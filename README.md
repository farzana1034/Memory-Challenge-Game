# 🧠 Memory Challenge Game

## 📌 Project Description

Memory Challenge Game is an interactive web-based game developed using Python and Streamlit. The application tests a player's short-term memory by displaying a sequence of random numbers for a limited amount of time.

After the numbers disappear, the player must enter the numbers they remember. The application compares the player's response with the original sequence and calculates the score and accuracy.

## 🎯 Objectives

* To create an interactive memory training application.
* To test short-term memory and concentration.
* To provide different difficulty levels.
* To calculate the player's score and accuracy.
* To provide a simple and user-friendly web interface.

## 🚀 Features

* Easy, Medium, and Hard difficulty levels
* Random number generation
* Time-based memory challenge
* Automatic score calculation
* Accuracy calculation
* Best score tracking
* Play Again option
* Interactive Streamlit interface

## 🎮 How the Game Works

1. Select a difficulty level.
2. Click the Start Memory Challenge button.
3. Memorize the displayed numbers.
4. Wait until the numbers disappear.
5. Enter the numbers you remember.
6. Click Check My Answer.
7. View your score and accuracy.
8. Click Play Again to start another challenge.

## 📊 Difficulty Levels

| Level  | Number of Items | Memory Time |
| ------ | --------------: | ----------: |
| Easy   |               4 |   5 seconds |
| Medium |               6 |   4 seconds |
| Hard   |               8 |   3 seconds |

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Memory-Challenge-Game.git
```

Open the project folder:

```bash
cd Memory-Challenge-Game
```

Create a virtual environment:

```bash
python -m venv venv
```

Install the required package:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
